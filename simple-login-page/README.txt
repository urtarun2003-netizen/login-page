SIMPLE LOGIN PAGE

Files:
- index.html
- style.css
- script.js

GITHUB PAGES:
1. Create a new GitHub repository.
2. Upload all three files.
3. Go to Settings > Pages.
4. Select Deploy from a branch.
5. Select main and / (root).
6. Click Save.
7. Open the GitHub Pages URL.

NOTE:
This is a front-end demo. It does not securely authenticate users or store passwords.
